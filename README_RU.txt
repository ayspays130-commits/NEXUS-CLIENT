NEXUS CLIENT — Fabric 1.21.11
================================

Что есть в этой стартовой версии:
- Открытие ClickGUI на RIGHT SHIFT.
- Вкладки PLAYER / COMBAT / RENDER / MOVEMENT / MISC.
- Переключатели модулей (пока это демонстрационные переключатели интерфейса).
- Тёмный интерфейс с фиолетовыми акцентами.

Важно:
Это ИСХОДНЫЙ ПРОЕКТ, а не готовый .jar. Я не запускал сборку и не могу подтвердить,
что проект уже скомпилирован. Для сборки требуется компьютер с JDK 21 и Gradle:
    gradle build

Готовый файл после успешной сборки появится в:
    build/libs/

Для PojavLauncher:
1. Сначала установи Fabric Loader именно для Minecraft 1.21.11.
2. Скопируй собранный nexus-client-1.0.0.jar в папку .minecraft/mods.
3. Также положи туда Fabric API версии 0.141.1+1.21.11.
4. Запусти профиль Fabric 1.21.11.

На одном телефоне через PojavLauncher исходный проект сам по себе не соберётся:
для компиляции нужен JDK/Gradle build environment. В этой версии нет аимбота,
автоматизации боя или функций для нечестного преимущества на публичных серверах.


СБОРКА В ОБЛАКЕ С ТЕЛЕФОНА (GitHub Actions):
1. Создай новый репозиторий на GitHub.
2. Загрузи туда ВСЕ файлы и папки из этого проекта, включая скрытую папку .github.
3. Открой вкладку Actions в репозитории.
4. Выбери workflow "Build NEXUS CLIENT" и нажми Run workflow (или дождись сборки после загрузки в main).
5. Когда запуск завершится успешно, открой его страницу и скачай artifact "nexus-client-jar".
6. Распакуй artifact ZIP — внутри будет JAR.

Если сборка завершится ошибкой, пришли скриншот красного сообщения из Actions.
Этот workflow только запускает сборку; успешная компиляция заранее не гарантируется.
